# MZ.dev — Portfólio de Mário

Portfólio pessoal de **Mário**, estudante do 3º semestre do **Bacharelado em Tecnologia da Informação na UFERSA**.

> Este portfólio é um registro da minha evolução na Tecnologia da Informação.

## Estrutura

```text
MZ_Portfolio/
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
    └── (reservado para futuras imagens)
```

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript puro
- Google Fonts (carregadas por CSS)

Não há necessidade de Node.js, PHP, banco de dados ou servidor.

## Como testar

1. Extraia a pasta.
2. Abra `index.html` diretamente no navegador.
3. Navegue pelas seções.

O projeto foi feito para funcionar como um site estático.

## Como publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie `index.html`, `style.css`, `script.js`, `README.md` e a pasta `assets`.
3. No repositório, abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch principal (normalmente `main`) e a pasta `/ (root)`.
6. Salve e aguarde a publicação.

Como todos os arquivos utilizam caminhos relativos, o projeto pode ficar dentro de um repositório GitHub sem depender de backend.

## Antes de publicar

Na seção **Contato**, substitua os placeholders:

- `https://github.com/SEU_USUARIO`
- `https://linkedin.com/in/SEU_USUARIO`
- `seuemail@example.com`

Também é possível adicionar novos registros ao diário duplicando um elemento `.diary-entry` no `index.html`.
